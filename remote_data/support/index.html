Nepal HelpLine Support

Help for the independent Nepal HelpLine public phone directory app.

For an immediate emergency, call national emergency numbers first. Nepal HelpLine is a directory app, not an emergency dispatch or government warning service.

Request support or report a problem

Email wrr094@gmail.com to report an app problem, incorrect contact detail, missing organisation, accessibility concern, or privacy question.

You may also use the support request page. A free GitHub account may be required to submit a request.

Open support request

To help resolve an issue, include the app version, device model, operating-system version, and a short description. Do not include personal emergency-contact details, sensitive personal information, or emergency reports.

Directory information and corrections

Contact details can change. Each current directory record has an original source URL, source type, verification status, and last checked date. Verify critical services directly with the original source where possible.
